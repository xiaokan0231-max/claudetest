# YouTube Trend Analysis Report Template

# YouTube SNS 趋势分析报告

## 执行摘要

- 数据来源、分析期间和观测时间
- 视频、关键词和热门榜样本数量
- 最重要的三个发现与最高优先级行动

## 数据范围与局限

- YouTube Data API v3，日本 `JP`，语言偏好 `ja`
- 本次采集消耗与本地配额预算
- 缺失点赞或评论数的视频数量
- 未公开的分享、收藏、点击、观看时长和流量来源
- 关键词结果数为近似值，Shorts `viewCount` 口径变化

## 高表现与增长视频

使用最新浏览数、浏览增长、每日增长和反应率，并标记低基数反应率。

## 热门主题、关键词和热门榜

按关键词主题、分类和标签描述样本表现；描述关键词近似结果数变化和热门榜持续出现次数。

## 数据支持的事实

只写快照或确定性计算直接支持的结论。

## 合理推测

将主题、标题、时长、频道规模或热门榜表现作为可能的解释，不写成因果关系。

## 仍需验证

说明需要 YouTube Analytics、更多连续快照或内容实验才能验证的假设。

## 企划与改善建议

每条建议使用：

```text
行动 -> 依据 -> 预期信号 -> 验证方法
```
